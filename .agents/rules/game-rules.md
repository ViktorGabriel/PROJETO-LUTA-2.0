# Regras de Desenvolvimento do Projeto Luta RPG

1. **Apresentação e UI Premium**: Mantenha visual dark fantasy moderno com glassmorphism, sombras pronunciadas, tipografia temática e alta legibilidade.
2. **Combate Balanceado e Interativo**: Mantenha feedback visual instantâneo para todas as ações do jogador (números flutuantes de dano, tremor de tela, barras de vida responsivas e logs de combate coloridos).
3. **Padrão Funcional Limpo**: Preserve a estrutura de factory functions para heróis e monstros, permitindo fácil expansão com novos personagens.
4. **Sem Dependências Quebráveis**: Priorize recursos nativos do navegador (Web Audio API, Vanilla CSS, JS ES6+).
